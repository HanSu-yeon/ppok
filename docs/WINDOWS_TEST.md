# Windows 실기 검증 체크리스트

팝업·트레이·자동 실행·전체 화면 감지는 운영체제에 따라 동작이 달라서 **실제 Windows 10/11**에서 확인해야 합니다.
macOS 개발 환경에서는 로직(Rust 테스트)과 화면만 확인했습니다.

## 0. 준비

### A. Windows PC에서 직접 빌드
```powershell
# 1회: Rust(https://rustup.rs), Node 22, "Visual Studio Build Tools - C++ 데스크톱 개발" 설치
npm ci
npm run tauri dev        # 개발 실행
npm run tauri build      # 설치 파일: src-tauri\target\release\bundle\nsis\뽁_0.1.0_x64-setup.exe
```

### B. GitHub Actions
저장소에 올린 뒤 Actions → **Windows build** → Run workflow → 아티팩트 `ppok-windows-installer` 다운로드.

빠른 테스트 팁: 설정 → 팝업 → 등장 간격 → **직접 입력 5분**으로 두거나, 트레이의 **지금 단어 보기**를 쓰세요.
로그: `%LOCALAPPDATA%\app.ppok.desktop\logs\` · DB: `%APPDATA%\app.ppok.desktop\ppok.db`
